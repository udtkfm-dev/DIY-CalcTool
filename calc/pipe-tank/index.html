タンクの容量と満水時間の計算

容量と流量から、満水までにかかる時間を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

タンクの容量と満水時間でできること

タンクの容量と満水時間は、容量・流量・かかる時間のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：タンク、貯水、満水、時間、容量、給水

入力できる値

項目選べる単位説明
容量mm³ / cm³ / m³ / L / mL
流量L/min / L/s / m³/h / m³/s
かかる時間—単位は分

計算で求まる値

  • 容量mm³ / cm³ / m³ / L / mL
  • 流量L/min / L/s / m³/h / m³/s
  • かかる時間（分）
  • かかる時間（時間）

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 容量・流量→かかる時間・かかる時間（時間）
  • 流量・かかる時間→容量・かかる時間（時間）

DIYでの使いどころ

満水までの時間

容量 ÷ 流量。200Lのタンクを毎分20Lで満たすなら10分です。 逆に、時間から必要な流量を求めることもできます。

実際は計算より長い

流量は水圧で変わり、タンクに水が溜まるほど背圧で落ちることがあります。 また、ホースの細さや継手の抵抗でも下がります。 計算値は「これより短くはならない」下限として見てください。

計算式

タンクの容量と満水時間で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 時間[分] = 容量[L] ÷ 流量[L/min]
  • 時間[時] = 分 ÷ 60
  • 容量[L] = 流量[L/min] × 時間[分]

計算例

200Lのタンクを20L/minで満たす

入力

  • 容量200 L
  • 流量20 L/min

結果

  • かかる時間10
  • かかる時間（時間）0.17

この例の計算過程

式数字を入れると答え
時間[分] = 容量[L] ÷ 流量[L/min]200 ÷ 2010 分
時間[時] = 分 ÷ 6010 ÷ 600.17 時間

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから タンクの容量と満水時間 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

タンクの容量と満水時間のよくある質問

タンクの容量と満水時間は何が分かれば計算できますか？

容量・流量を入力するとかかる時間・かかる時間（時間）が求まります。流量・かかる時間を入力すると容量・かかる時間（時間）が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば流量・かかる時間を入れると容量・かかる時間（時間）が求まります。逆算用の別画面はありません。

タンクの容量と満水時間で使える単位は何ですか？

容量は mm³ / cm³ / m³ / L / mL、流量は L/min / L/s / m³/h / m³/s から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

タンクの容量と満水時間以外の配管・排水の計算もありますか？

あります。配管・排水のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
