割合・増減率でできること

割合・増減率は、もとの値・割合・割合をかけた値のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：割合、パーセント、％、増減率、ロス率、割引、増加、減少

DIYでの使いどころ

ロス率・割増の計算に

材料を「10%多めに」買うときの数量、値引き後の金額、面積の割増など、 DIYでも割合の計算は頻繁に出てきます。 もとの値と割合を入れれば結果が、結果ともとの値を入れれば割合が出ます。

「10%増やして10%減らす」は元に戻らない

1000を10%増やすと1100、そこから10%減らすと990で、元の1000には戻りません。 掛ける相手が変わるためです。値引き後の金額から元の値段を逆に出したいときは、 「割合をかけた値」と「割合」を入れて、もとの値を求めてください。

計算式

割合・増減率で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • value = base × pct ÷ 100
  • diff = value − base
  • pct = value ÷ base × 100
  • base = value ÷ pct × 100

記号の意味：base = もとの値、pct = 割合、value = 割合をかけた値、diff = 差

計算例

1800に対する10%の値を求める

入力

  • もとの値1,800
  • 割合10%

結果

  • 割合をかけた値180
  • 差-1,620

この例の計算過程

式数字を入れると答え
value = base × pct ÷ 1001,800 × 10 ÷ 100180
diff = value − base180 − 1,800-1,620

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 割合・増減率 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

割合・増減率のよくある質問

割合・増減率は何が分かれば計算できますか？

もとの値・割合を入力すると割合をかけた値・差が求まります。もとの値・割合をかけた値を入力すると割合・差が求まります。割合・割合をかけた値を入力するともとの値・差が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば割合・割合をかけた値を入れるともとの値・差が求まります。逆算用の別画面はありません。

割合・増減率以外の長さ・単位の計算もありますか？

あります。長さ・単位のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
