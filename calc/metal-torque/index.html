ねじの締付トルクの計算

トルク係数・呼び径・軸力から締付トルクを計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

ねじの締付トルクでできること

ねじの締付トルクは、トルク係数 K・ねじの呼び径・軸力・締付トルクのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：トルク、締付、ねじ、ボルト、軸力、N・m、トルクレンチ

入力できる値

項目選べる単位説明
トルク係数 K—潤滑なしの鋼ボルトで 0.2 前後、潤滑ありで 0.15 前後が目安
ねじの呼び径mm / cm / m / inch / ft / 尺 / 寸M8 なら 8mm
軸力N / kN / kgfボルトに生じさせたい引張力
締付トルクN·m / kgf·m

計算で求まる値

  • トルク係数
  • 呼び径mm / cm / m / inch / ft / 尺 / 寸
  • 軸力N / kN / kgf
  • 締付トルクN·m / kgf·m

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • トルク係数 K・ねじの呼び径・軸力→締付トルク
  • トルク係数 K・ねじの呼び径・締付トルク→軸力

DIYでの使いどころ

締付トルク = K × 呼び径 × 軸力

ボルトを締める力（トルク）と、そこで生まれる軸力（ボルトが部材を挟む力）の関係式です。 必要な軸力から、締めるべきトルクを求めます。

トルク係数 K

ねじ面と座面の摩擦の状態を表す値で、0.15〜0.25 程度。 潤滑の有無、めっきの種類、座面の粗さで変わります。 無潤滑の一般的なボルトでは 0.2 前後がよく使われます。

トルクだけでは軸力は決まらない

同じトルクで締めても、摩擦のばらつきで実際の軸力は大きく振れます。 重要な締結では、トルク法ではなく回転角法や軸力測定が使われます。 安全に関わる部分はメーカーの締付基準に従ってください。

計算式

ねじの締付トルクで使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • T = K × 呼び径[m] × 軸力
  • 軸力 = T ÷ (K × 呼び径[m])

記号の意味：K = トルク係数 K、T = 締付トルク

計算例

M8のボルトに軸力5000N、トルク係数0.2で締める

入力

  • トルク係数 K0.2
  • ねじの呼び径8 mm
  • 軸力5,000 N

結果

  • 締付トルク8 N·m

この例の計算過程

式数字を入れると答え
T = K × 呼び径[m] × 軸力0.2 × 0.01 × 5,0008 N·m

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから ねじの締付トルク の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

ねじの締付トルクのよくある質問

ねじの締付トルクは何が分かれば計算できますか？

トルク係数 K・ねじの呼び径・軸力を入力すると締付トルクが求まります。トルク係数 K・ねじの呼び径・締付トルクを入力すると軸力が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえばトルク係数 K・ねじの呼び径・締付トルクを入れると軸力が求まります。逆算用の別画面はありません。

ねじの締付トルクで使える単位は何ですか？

ねじの呼び径は mm / cm / m / inch / ft / 尺 / 寸、軸力は N / kN / kgf、締付トルクは N·m / kgf·m から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

ねじの締付トルク以外の金属加工・機械の計算もありますか？

あります。金属加工・機械のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。

ご利用にあたっての注意

  • 本アプリは寸法・数学の計算を支援するツールです。施工の可否や安全性は判断できません。
  • 加工条件・締付力は材料や工具、機械の状態で変わります。実際の値はメーカーの資料や現場の基準にあわせてご確認ください。
  • トルク係数は表面処理・潤滑・座面の状態で大きく変わります。強度区分ごとの締付値はねじの規格や機器の指定をご確認ください。
