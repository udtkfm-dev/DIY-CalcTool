体積の単位換算でできること

体積の単位換算は、mm³・cm³・m³・L・mLのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：体積、単位、換算、リットル、L、mL、容量

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • mm³→cm³・m³・L・mL
  • cm³→mm³・m³・L・mL
  • m³→mm³・cm³・L・mL
  • L→mm³・cm³・m³・mL
  • mL→mm³・cm³・m³・L

DIYでの使いどころ

Lとm³の関係

1m³ = 1000L、1L = 1000cm³ = 1000mL。 生コンやまき土は m³、灯油や塗料は L、というように扱う単位が分野で分かれるため、 発注のときに桁を間違えやすい場所です。

DIYでよく使う目安

ポリタンク1つが約18〜20L、バケツ1杯が約10L。 0.1m³ = 100L はバケツ10杯ぶんです。 「m³で言われたけれど、バケツで何杯か」を掴むときに使えます。

計算式

体積の単位換算で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 1,000,000 mm³ を cm³ に換算
  • 1,000,000 mm³ を m³ に換算
  • 1,000,000 mm³ を L に換算
  • 1,000 cm³ を mm³ に換算
  • 1,000 cm³ を m³ に換算
  • 1,000 cm³ を L に換算
  • 0 m³ を mm³ に換算
  • 0 m³ を cm³ に換算
  • 0 m³ を L に換算
  • 20 L を mm³ に換算
  • 20 L を cm³ に換算
  • 20 L を m³ に換算
  • 1,000 mL を mm³ に換算
  • 1,000 mL を cm³ に換算
  • 1,000 mL を m³ に換算

記号の意味：L = L、mL = mL

使い方

  1. 上のボタンから 体積の単位換算 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

体積の単位換算のよくある質問

体積の単位換算は何が分かれば計算できますか？

mm³を入力するとcm³・m³・L・mLが求まります。cm³を入力するとmm³・m³・L・mLが求まります。m³を入力するとmm³・cm³・L・mLが求まります。このほか2通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえばmLを入れるとmm³・cm³・m³・Lが求まります。逆算用の別画面はありません。

体積の単位換算で使える単位は何ですか？

mm³は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

体積の単位換算以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
