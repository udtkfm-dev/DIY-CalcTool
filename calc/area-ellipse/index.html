楕円の面積の計算

長半径・短半径・面積を相互計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

楕円の面積でできること

楕円の面積は、長半径・短半径・面積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：面積、楕円、広さ

入力できる値

項目選べる単位説明
長半径mm / cm / m / inch / ft / 尺 / 寸
短半径mm / cm / m / inch / ft / 尺 / 寸
面積mm² / cm² / m² / 坪 / 畳

計算で求まる値

  • 長半径mm / cm / m / inch / ft / 尺 / 寸
  • 短半径mm / cm / m / inch / ft / 尺 / 寸
  • 面積mm² / cm² / m² / 坪 / 畳

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 長半径・短半径→面積
  • 面積・長半径→短半径
  • 面積・短半径→長半径

DIYでの使いどころ

楕円の面積は π × 長半径 × 短半径

円の面積 πr² の r を、長いほうの半径と短いほうの半径に分けた形です。 「半径」であって「直径」ではないので、測った差し渡しの寸法は半分にして入れてください。

DIYで楕円が出てくる場面

楕円形のテーブル天板、丸パイプを斜めに切った断面、 だ円の鏡や窓の開口など。周長は簡単な式では表せない（近似式になる）ため、 このアプリでは面積を扱っています。

計算式

楕円の面積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • S = π × a × b
  • b = S ÷ (π × a)
  • a = S ÷ (π × b)

記号の意味：a = 長半径、b = 短半径、S = 面積

計算例

長半径600mm・短半径400mmの楕円

入力

  • 長半径0.6 m
  • 短半径0.4 m

結果

  • 面積0.75 m²

S = π × a × bπ × 0.6 × 0.40.75 m²

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 楕円の面積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

楕円の面積のよくある質問

楕円の面積は何が分かれば計算できますか？

長半径・短半径を入力すると面積が求まります。面積・長半径を入力すると短半径が求まります。面積・短半径を入力すると長半径が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば面積・短半径を入れると長半径が求まります。逆算用の別画面はありません。

楕円の面積で使える単位は何ですか？

長半径は mm / cm / m / inch / ft / 尺 / 寸、面積は mm² / cm² / m² / 坪 / 畳 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

楕円の面積以外の面積の計算もありますか？

あります。面積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
