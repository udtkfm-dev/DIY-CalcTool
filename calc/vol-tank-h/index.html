横置きタンクの液量の計算

横に寝かせた円筒タンクの、液面の深さから残量を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

横置きタンクの液量でできること

横置きタンクの液量は、タンクの直径・タンクの長さ・液面の深さのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：タンク、横置き、残量、液量、雨水、ドラム缶、燃料、水槽

入力できる値

項目選べる単位説明
タンクの直径mm / cm / m / inch / ft / 尺 / 寸
タンクの長さmm / cm / m / inch / ft / 尺 / 寸
液面の深さmm / cm / m / inch / ft / 尺 / 寸底から液面までの高さ

計算で求まる値

  • 液面下の断面積mm² / cm² / m² / 坪 / 畳
  • 満水量(L)mm³ / cm³ / m³ / L / mL
  • 満水に対する割合%
  • 体積(mm³)mm³ / cm³ / m³ / L / mL
  • 体積(m³)mm³ / cm³ / m³ / L / mL
  • 体積(L)mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • タンクの直径・タンクの長さ・液面の深さ→液面下の断面積・満水量(L)・満水に対する割合・体積(mm³)・体積(m³)・体積(L)

DIYでの使いどころ

横に寝かせたタンクは液面の高さと量が比例しない

縦置きのタンクなら液面の高さと量は比例しますが、横置き（円筒を寝かせた形）は違います。 真ん中あたりは断面が広いので、同じ1cmでも入る量が多く、 上下の端では少なくなります。目視の高さから量を読むには、この計算が要ります。

半分の深さでちょうど半分

直径のちょうど半分の深さのときだけ、量も満水の50%になります。 それ以外は比例しません。灯油タンク・雨水タンク・オイルタンクの残量把握に使えます。

計算式

横置きタンクの液量で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 半径 = 直径 ÷ 2
  • 断面積 = r²·acos((r − y) ÷ r) − (r − y)·√(2ry − y²)
  • 液量 = 断面積 × 長さ
  • 満水量 = π × r² × 長さ

計算例

直径600mm・長さ1200mmの横置きタンクに水が300mm入っているときの残量

入力

  • タンクの直径0.6 m
  • タンクの長さ1.2 m
  • 液面の深さ0.3 m

結果

  • 液面下の断面積0.14 m²
  • 満水量(L)339.29 L
  • 満水に対する割合50%
  • 体積(mm³)169,646,003.29 mm³
  • 体積(m³)0.17 m³
  • 体積(L)169.65 L

この例の計算過程

式数字を入れると答え
半径 = 直径 ÷ 20.6 ÷ 20.3 m
断面積 = r²·acos((r − y) ÷ r) − (r − y)·√(2ry − y²)r=0.3, y=0.30.14 m²
液量 = 断面積 × 長さ0.14 × 1.2169.65 L
満水量 = π × r² × 長さπ × 0.3² × 1.2339.29 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 横置きタンクの液量 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

横置きタンクの液量のよくある質問

横置きタンクの液量は何が分かれば計算できますか？

タンクの直径・タンクの長さ・液面の深さを入力すると液面下の断面積・満水量(L)・満水に対する割合・体積(mm³)・体積(m³)・体積(L)が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

横置きタンクの液量で使える単位は何ですか？

タンクの直径は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

横置きタンクの液量以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
