塗料の希釈の計算

希釈率から、混ぜるうすめ液の量と合計量を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

塗料の希釈でできること

塗料の希釈は、塗料の量・希釈率（%）・うすめ液の量・希釈後の合計のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：希釈、うすめ液、シンナー、塗料、配合、割合、スプレー、吹き付け

入力できる値

項目選べる単位説明
塗料の量mm³ / cm³ / m³ / L / mL
希釈率（%）—塗料に対するうすめ液の割合。刷毛塗りで5〜10%、スプレーで30〜50%が目安
うすめ液の量mm³ / cm³ / m³ / L / mL
希釈後の合計mm³ / cm³ / m³ / L / mL

計算で求まる値

  • 塗料の量mm³ / cm³ / m³ / L / mL
  • うすめ液の量mm³ / cm³ / m³ / L / mL
  • 希釈率（%）
  • 希釈後の合計mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 塗料の量・希釈率（%）→うすめ液の量・希釈後の合計
  • 希釈後の合計・希釈率（%）→塗料の量・うすめ液の量
  • 塗料の量・うすめ液の量→希釈率（%）・希釈後の合計

DIYでの使いどころ

希釈率は「塗料に対する割合」

「10%希釈」は、塗料1000mLに対してうすめ液100mLを足すという意味です。 合計は1100mLになります。 仕上がり量に対する割合ではないので、逆に計算すると量が合いません。

薄めすぎると隠ぺい力が落ちる

塗りやすくなるからと薄めすぎると、下地が透けて塗り重ねが増え、 結局は塗料を多く使うことになります。 希釈率は製品の缶に書かれた範囲を守ってください。

うすめ液の種類

水性塗料は水、油性塗料はペイントうすめ液（ミネラルスピリット）、 ラッカーはラッカーシンナーと、対応する溶剤が決まっています。 違うものを混ぜると分離したり固まったりします。

計算式

塗料の希釈で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • うすめ液 = 塗料 × 希釈率 ÷ 100
  • 合計 = 塗料 + うすめ液
  • 塗料 = 合計 ÷ (1 + 希釈率 ÷ 100)
  • うすめ液 = 合計 − 塗料
  • 希釈率 = うすめ液 ÷ 塗料 × 100

計算例

塗料1000mLを10%希釈する

入力

  • 塗料の量1,000 mL
  • 希釈率（%）10

結果

  • うすめ液の量100 mL
  • 希釈後の合計1,100 mL

この例の計算過程

式数字を入れると答え
うすめ液 = 塗料 × 希釈率 ÷ 1001,000 × 10 ÷ 100100 mL
合計 = 塗料 + うすめ液1,000 + 1001,100 mL

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 塗料の希釈 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

塗料の希釈のよくある質問

塗料の希釈は何が分かれば計算できますか？

塗料の量・希釈率（%）を入力するとうすめ液の量・希釈後の合計が求まります。希釈後の合計・希釈率（%）を入力すると塗料の量・うすめ液の量が求まります。塗料の量・うすめ液の量を入力すると希釈率（%）・希釈後の合計が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば塗料の量・うすめ液の量を入れると希釈率（%）・希釈後の合計が求まります。逆算用の別画面はありません。

塗料の希釈で使える単位は何ですか？

塗料の量は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

塗料の希釈以外の塗装・壁紙の計算もありますか？

あります。塗装・壁紙のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
