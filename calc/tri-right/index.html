直角三角形の計算

底辺・高さ・斜辺・角度を相互計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

直角三角形でできること

直角三角形は、底辺・高さ・斜辺・角A・角Cのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：斜め、斜辺、三平方、ピタゴラス、直角、角度、屋根、筋交い

DIYでの使いどころ

DIYで直角三角形の計算を使う場面

板を斜めに切る、棚を斜めに支える、枠が直角かを確かめる——DIYで「斜め」が出てくる場面は、 ほとんどが直角三角形の計算に置き換えられます。底辺と高さの2つが分かれば斜辺（斜めの長さ）と 両端の角度が決まるので、丸ノコの角度を何度に合わせればよいかがその場で分かります。

3-4-5 の直角出しを実寸で行う

基礎や土台の直角を出すとき、3:4:5 の辺の比が直角三角形になることを使う方法があります。 このとき「900mm と 1200mm を測ったら対角は何mmになるか」を出すのが、この計算の使い方です。 答えは 1500mm。実際の現場では 900・1200 のように切りのいい数字が取れないことも多いので、 測った実寸をそのまま入れて対角を出すほうが確実です。

角度から寸法を逆に出す

「30度の勾配で 600mm 上げたい」のように、角度が先に決まっている場合は、 角度と高さを入れれば底辺と斜辺が出ます。丸ノコやスライド丸ノコの角度目盛りに合わせる値と、 実際に切る材の長さを、同じ画面で確認できます。

計算式

直角三角形で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • c = √(a² + b²)
  • A = atan(b ÷ a)
  • C = 90° − A
  • 勾配 = b ÷ a × 100
  • 面積 = a × b ÷ 2
  • b = √(c² − a²)
  • A = acos(a ÷ c)
  • b = a × tan(A)
  • c = a ÷ cos(A)
  • a = b ÷ tan(A)
  • c = b ÷ sin(A)
  • a = c × cos(A)
  • b = c × sin(A)
  • A = 90° − C

記号の意味：a = 底辺、b = 高さ、c = 斜辺

計算例

底辺900mm・高さ1200mmの直角三角形で斜辺と角度を求める

入力

  • 底辺900 mm
  • 高さ1,200 mm

結果

  • 斜辺1,500 mm
  • 角A53.13°
  • 角C36.87°
  • 勾配133.33%
  • 面積540,000 mm²

使い方

  1. 上のボタンから 直角三角形 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

直角三角形のよくある質問

直角三角形は何が分かれば計算できますか？

底辺・高さを入力すると斜辺・角A・角C・面積・勾配が求まります。底辺・斜辺を入力すると高さ・角A・角C・面積・勾配が求まります。高さ・斜辺を入力すると底辺・角A・角C・面積・勾配が求まります。このほか6通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば斜辺・角Cを入れると底辺・高さ・角A・面積・勾配が求まります。逆算用の別画面はありません。

直角三角形で使える単位は何ですか？

底辺は mm / cm / m / inch / ft / 尺 / 寸、角Aは ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

直角三角形以外の三角・角度の計算もありますか？

あります。三角・角度のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
