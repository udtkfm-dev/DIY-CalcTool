円錐の体積でできること

円錐の体積は、半径・高さ・体積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：体積、円錐、容量

項目選べる単位説明

高さmm / cm / m / inch / ft / 尺 / 寸
体積mm³ / cm³ / m³ / L / mL

  • 高さmm / cm / m / inch / ft / 尺 / 寸
  • 体積(mm³)mm³ / cm³ / m³ / L / mL
  • 体積(m³)mm³ / cm³ / m³ / L / mL
  • 体積(L)mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 半径・高さ→体積(mm³)・体積(m³)・体積(L)
  • 体積・半径→高さ
  • 体積・高さ→半径

DIYでの使いどころ

円錐は同じ底面・高さの円柱の3分の1

π × 半径² × 高さ ÷ 3。 砂利や砂を円錐状に積んだときの量の見積もり、じょうごや三角コーンの容積などに使えます。

積んだ山の量を見積もる

地面に積み上げた砂や土の山はおおよそ円錐です。 裾の直径と高さを測れば、おおよその体積が出ます。 実際の山は完全な円錐ではないので、あくまで目安として使ってください。

計算式

円錐の体積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • V = πr²h ÷ 3
  • 高さ = 3V ÷ (πr²)
  • 半径 = √(3V ÷ (πh))

記号の意味：r = 半径、h = 高さ、V = 体積

計算例

半径150mm・高さ300mmの円錐

入力

  • 半径0.15 m
  • 高さ0.3 m

結果

  • 体積(mm³)7,068,583.47 mm³
  • 体積(m³)0.01 m³
  • 体積(L)7.07 L

この例の計算過程

式数字を入れると答え
V = πr²h ÷ 3π × 0.15² × 0.3 ÷ 37.07 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 円錐の体積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

円錐の体積のよくある質問

円錐の体積は何が分かれば計算できますか？

半径・高さを入力すると体積(mm³)・体積(m³)・体積(L)が求まります。体積・半径を入力すると高さが求まります。体積・高さを入力すると半径が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば体積・高さを入れると半径が求まります。逆算用の別画面はありません。

円錐の体積で使える単位は何ですか？

半径は mm / cm / m / inch / ft / 尺 / 寸、体積は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

円錐の体積以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
