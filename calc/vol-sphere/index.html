球の体積の計算

半径・体積を相互計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

球の体積でできること

球の体積は、半径・体積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：体積、球、ボール、容量

入力できる値

項目選べる単位説明
半径mm / cm / m / inch / ft / 尺 / 寸
体積mm³ / cm³ / m³ / L / mL

計算で求まる値

  • 半径mm / cm / m / inch / ft / 尺 / 寸
  • 体積(mm³)mm³ / cm³ / m³ / L / mL
  • 体積(m³)mm³ / cm³ / m³ / L / mL
  • 体積(L)mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 半径→体積(mm³)・体積(m³)・体積(L)
  • 体積→半径

DIYでの使いどころ

球の体積は (4/3) × π × 半径³

半径の3乗が効くので、直径を少し測り違えるだけで体積は大きくずれます。 直径しか測れないときは、必ず半分にしてから入れてください。

半球（ドーム）のとき

ドーム状の形は、この計算で出した値の半分になります。 半球型の鉢や、丸屋根の内容積などに使えます。

計算式

球の体積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • V = 4πr³ ÷ 3
  • r = ∛(3V ÷ (4π))

記号の意味：r = 半径、V = 体積

計算例

半径150mmの球

入力

  • 半径0.15 m

結果

  • 体積(mm³)14,137,166.94 mm³
  • 体積(m³)0.01 m³
  • 体積(L)14.14 L

この例の計算過程

式数字を入れると答え
V = 4πr³ ÷ 34π × 0.15³ ÷ 314.14 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 球の体積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

球の体積のよくある質問

球の体積は何が分かれば計算できますか？

半径を入力すると体積(mm³)・体積(m³)・体積(L)が求まります。体積を入力すると半径が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば体積を入れると半径が求まります。逆算用の別画面はありません。

球の体積で使える単位は何ですか？

半径は mm / cm / m / inch / ft / 尺 / 寸、体積は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

球の体積以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
