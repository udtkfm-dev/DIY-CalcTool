任意三角形の計算

3辺・3角のうち3つから残りを計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

任意三角形でできること

任意三角形は、辺a・辺b・辺c・角A・角B・角Cのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：三角形、正弦定理、余弦定理、ヘロン、面積、辺、角度

DIYでの使いどころ

直角でない三角形を扱うとき

屋根の谷、変形地の区画、斜めに交わる部材など、直角が無い三角形はDIYでもよく出てきます。 3辺・3角の6つのうち3つ（ただし3つとも角度ではだめ）が分かれば、残りはすべて決まります。 角度だけでは形は決まっても大きさが決まらないためです。

測った3辺から角度を出す

現場では角度より長さのほうが正確に測れます。三角形の3辺を巻尺で測って入れれば、 3つの角度と面積が出ます。分度器を当てにくい大きな形ほど、この方法が確実です。

2辺と1角のときは注意

2辺とその「間」の角が分かる場合は形が1つに決まります。 一方、2辺とその間ではない角の場合、条件によっては三角形が2通り成立します。 入力した値で結果が思っていた形と違うときは、どの角を入れたかを確かめてください。

計算式

任意三角形で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • A = acos((b²+c²−a²)/(2bc))
  • B = acos((a²+c²−b²)/(2ac))
  • C = 180° − A − B
  • S = √(s(s−a)(s−b)(s−c))　s=(a+b+c)/2
  • 周長 = a + b + c
  • height_a = 2 × 面積 ÷ a
  • c = √(a² + b² − 2ab・cosC)
  • B = 180° − C − A
  • A = 180° − B − C
  • b = a × sinB ÷ sinA
  • c = a × sinC ÷ sinA
  • sinB = b × sinA ÷ a

記号の意味：a = 辺a、b = 辺b、c = 辺c、height_a = 高さ(aから)

計算例

3辺が900・1200・1500mmの三角形の角度を求める

入力

  • 辺a900 mm
  • 辺b1,200 mm
  • 辺c1,500 mm

結果

  • 角A36.87°
  • 角B53.13°
  • 角C90°
  • 面積540,000 mm²
  • 周長3,600 mm
  • 高さ(aから)1,200 mm

この例の計算過程

式数字を入れると答え
A = acos((b²+c²−a²)/(2bc))acos((1,200² + 1,500² − 900²) ÷ (2×1,200×1,500))36.87°
B = acos((a²+c²−b²)/(2ac))acos((900² + 1,500² − 1,200²) ÷ (2×900×1,500))53.13°
C = 180° − A − B180° − 36.87° − 53.13°90°
S = √(s(s−a)(s−b)(s−c))　s=(a+b+c)/2s=1,800540,000 mm²
周長 = a + b + c900 + 1,200 + 1,5003,600 mm
height_a = 2 × 面積 ÷ a2 × 540,000 ÷ 9001,200 mm

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 任意三角形 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

任意三角形のよくある質問

任意三角形は何が分かれば計算できますか？

辺a・辺b・辺cを入力すると角A・角B・角C・面積・周長・高さ(aから)が求まります。辺a・辺b・角Cを入力すると辺c・角A・角B・面積・周長・高さ(aから)が求まります。辺a・角B・角Cを入力すると辺b・辺c・角A・面積・周長・高さ(aから)が求まります。このほか1通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば辺a・辺b・角Aを入れると辺c・角B・角C・面積・周長・高さ(aから)が求まります。逆算用の別画面はありません。

任意三角形で使える単位は何ですか？

辺aは mm / cm / m / inch / ft / 尺 / 寸、角Aは ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

任意三角形以外の三角・角度の計算もありますか？

あります。三角・角度のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
