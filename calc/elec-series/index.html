直列合成抵抗の計算

2〜4個の抵抗（直列）から合成抵抗を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

直列合成抵抗でできること

直列合成抵抗は、抵抗1・抵抗2・抵抗3・抵抗4のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：直列、合成抵抗、抵抗、Ω

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 抵抗1・抵抗2・抵抗3・抵抗4→合成抵抗
  • 抵抗1・抵抗2・抵抗3→合成抵抗
  • 抵抗1・抵抗2→合成抵抗

DIYでの使いどころ

直列はそのまま足す

抵抗を直列につなぐと、合成抵抗は単純な足し算になります。 100Ωと200Ωで300Ω。電流はどこでも同じで、 電圧が抵抗の比で分かれます（分圧）。

分圧に使う

「5Vを3.3Vに落としたい」といった用途で、抵抗2本の直列がよく使われます。 ただし電流が流れる先の負荷によって電圧が変わるので、 安定した電源が要る場合はレギュレータを使ってください。

計算式

直列合成抵抗で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 合成抵抗 = R1 + R2

記号の意味：R1 = 抵抗1、R2 = 抵抗2

計算例

100Ωと200Ωを直列につなぐ

入力

  • 抵抗1100 Ω
  • 抵抗2200 Ω

結果

  • 合成抵抗300 Ω

この例の計算過程

式数字を入れると答え
合成抵抗 = R1 + R2100 + 200300 Ω

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 直列合成抵抗 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

直列合成抵抗のよくある質問

直列合成抵抗は何が分かれば計算できますか？

抵抗1・抵抗2・抵抗3・抵抗4を入力すると合成抵抗が求まります。抵抗1・抵抗2・抵抗3を入力すると合成抵抗が求まります。抵抗1・抵抗2を入力すると合成抵抗が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば抵抗1・抵抗2を入れると合成抵抗が求まります。逆算用の別画面はありません。

直列合成抵抗以外の電気の計算もありますか？

あります。電気のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
