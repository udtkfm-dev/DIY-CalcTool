インチの分数 ⇄ ミリでできること

インチの分数 ⇄ ミリは、整数部（インチ）・分子・分母・ミリのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：インチ、分数、inch、1/16、3/8、ミリ、換算、工具

分母—3/8 の 8。ミリから戻すときは、丸める細かさ（16・32など）として使う

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 整数部（インチ）・分子・分母→インチ（小数）・ミリ
  • ミリ・分母→インチ（小数）・整数部（インチ）・分子

DIYでの使いどころ

インチの分数表記に慣れる

工具のビットやボルトは 1/4、3/8、1/2 のように分数で表されます。 1インチ = 25.4mm なので、3/8インチは 9.525mm。 日本のミリ表記の道具と混ぜて使うと、わずかな差でガタや締まりすぎが起きます。

ミリの穴にインチのボルトは入るか

1/4インチ = 6.35mm、3/8インチ = 9.525mm、1/2インチ = 12.7mm。 6mmの穴に1/4インチのボルトは入りません。逆に10mmの穴に3/8インチはガタが出ます。 買う前にここで換算して、手持ちのドリル径と突き合わせてください。

計算式

インチの分数 ⇄ ミリで使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • インチ = 整数部 + 分子 ÷ 分母
  • ミリ = インチ × 25.4
  • インチ = ミリ ÷ 25.4
  • 分母をかけて四捨五入
  • 帯分数にする

使い方

  1. 上のボタンから インチの分数 ⇄ ミリ の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

インチの分数 ⇄ ミリのよくある質問

インチの分数 ⇄ ミリは何が分かれば計算できますか？

整数部（インチ）・分子・分母を入力するとインチ（小数）・ミリが求まります。ミリ・分母を入力するとインチ（小数）・整数部（インチ）・分子が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえばミリ・分母を入れるとインチ（小数）・整数部（インチ）・分子が求まります。逆算用の別画面はありません。

インチの分数 ⇄ ミリで使える単位は何ですか？

ミリは mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

インチの分数 ⇄ ミリ以外の長さ・単位の計算もありますか？

あります。長さ・単位のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
