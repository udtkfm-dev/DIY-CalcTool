管内体積・水量の計算

内径・管長から、管の中に入る水の量を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

管内体積・水量でできること

管内体積・水量は、内径・管長・水量のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：配管、管内体積、水量、内径

入力できる値

項目選べる単位説明
内径mm / cm / m / inch / ft / 尺 / 寸
管長mm / cm / m / inch / ft / 尺 / 寸
水量mm³ / cm³ / m³ / L / mL

計算で求まる値

  • 内径mm / cm / m / inch / ft / 尺 / 寸
  • 管長mm / cm / m / inch / ft / 尺 / 寸
  • 体積(mm³)mm³ / cm³ / m³ / L / mL
  • 体積(L)mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 内径・管長→体積(mm³)・体積(L)
  • 水量・管長→内径
  • 水量・内径→管長

DIYでの使いどころ

管の中に入る水の量

内径から断面積を出し、管長を掛けたものが体積です。 「配管の水抜きにどれだけの容器が要るか」「不凍液をどれだけ入れるか」 といった場面で使います。

内径で計算する

管のサイズは呼び径（VP20、13Aなど）で表され、外径とも内径とも一致しません。 必ずカタログの内径を確認して入れてください。 外径で計算すると、肉厚のぶん多く出ます。

計算式

管内体積・水量で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • V = π × (内径÷2)² × 管長
  • 内径 = 2 × √(水量 ÷ (π×管長))
  • 管長 = 水量 ÷ (π×(内径÷2)²)

記号の意味：V = 水量

計算例

内径20mm・長さ10000mmの配管に入る水の量

入力

  • 内径20 mm
  • 管長10,000 mm

結果

  • 体積(mm³)3,141,592.65 mm³
  • 体積(L)3.14 L

この例の計算過程

式数字を入れると答え
V = π × (内径÷2)² × 管長π × (20÷2)² × 10,0003.14 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 管内体積・水量 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

管内体積・水量のよくある質問

管内体積・水量は何が分かれば計算できますか？

内径・管長を入力すると体積(mm³)・体積(L)が求まります。水量・管長を入力すると内径が求まります。水量・内径を入力すると管長が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば水量・内径を入れると管長が求まります。逆算用の別画面はありません。

管内体積・水量で使える単位は何ですか？

内径は mm / cm / m / inch / ft / 尺 / 寸、水量は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

管内体積・水量以外の配管・排水の計算もありますか？

あります。配管・排水のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
