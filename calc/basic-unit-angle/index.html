角度の単位換算でできること

角度の単位換算は、°・radのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：角度、単位、換算、ラジアン、rad、度

入力できる値

項目選べる単位説明
°° / rad
rad° / rad

計算で求まる値

  • °° / rad
  • rad° / rad

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • °→rad
  • rad→°

DIYでの使いどころ

度とラジアンを行き来する場面

工具の目盛りや図面はほぼすべて「度」ですが、表計算ソフトやプログラムの三角関数は ラジアンを使うものが多く、そのまま度を入れると答えが合いません。 Excelで SIN(30) としても 0.5 にならないのは、30をラジアンとして計算しているためです。

覚えておくと早い値

180度 = π ラジアン（約3.1416）。90度 = 約1.5708、45度 = 約0.7854、30度 = 約0.5236 です。

計算式

角度の単位換算で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 30° を rad に換算
  • 0.52 rad を ° に換算

記号の意味：rad = rad

計算例

30°をラジアンに直す

入力

  • °30°

結果

  • rad0.52 rad

この例の計算過程

式数字を入れると答え
30° を rad に換算30°0.52 rad

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 角度の単位換算 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

角度の単位換算のよくある質問

角度の単位換算は何が分かれば計算できますか？

°を入力するとradが求まります。radを入力すると°が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえばradを入れると°が求まります。逆算用の別画面はありません。

角度の単位換算で使える単位は何ですか？

°は ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

角度の単位換算以外の三角・角度の計算もありますか？

あります。三角・角度のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
