立方体の体積でできること

立方体の体積は、一辺・体積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：体積、立方体、サイコロ、容量

入力できる値

項目選べる単位説明
一辺mm / cm / m / inch / ft / 尺 / 寸
体積mm³ / cm³ / m³ / L / mL

計算で求まる値

  • 一辺mm / cm / m / inch / ft / 尺 / 寸
  • 体積(mm³)mm³ / cm³ / m³ / L / mL
  • 体積(m³)mm³ / cm³ / m³ / L / mL
  • 体積(L)mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 一辺→体積(mm³)・体積(m³)・体積(L)
  • 体積→一辺

DIYでの使いどころ

一辺だけで決まる

立方体は一辺の3乗が体積です。逆に体積から一辺（立方根）も出せるので、 「10Lの立方体の容器は何mm角か」といった逆算にも使えます。

一辺を2倍にすると体積は8倍

長さが2倍なら体積は2³ = 8倍。プランターや水槽を「ひと回り大きく」すると、 入る土や水は思ったよりずっと増えます。重さも同じ割合で増えるので、 置き場所の耐荷重にも関わります。

計算式

立方体の体積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • V = a³
  • a = ∛V

記号の意味：a = 一辺、V = 体積

計算例

一辺300mmの立方体

入力

  • 一辺0.3 m

結果

  • 体積(mm³)27,000,000 mm³
  • 体積(m³)0.03 m³
  • 体積(L)27 L

この例の計算過程

式数字を入れると答え
V = a³0.3³27 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 立方体の体積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

立方体の体積のよくある質問

立方体の体積は何が分かれば計算できますか？

一辺を入力すると体積(mm³)・体積(m³)・体積(L)が求まります。体積を入力すると一辺が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば体積を入れると一辺が求まります。逆算用の別画面はありません。

立方体の体積で使える単位は何ですか？

一辺は mm / cm / m / inch / ft / 尺 / 寸、体積は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

立方体の体積以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
