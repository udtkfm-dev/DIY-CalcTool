線分の等分の計算

全長と分割数から、等間隔の各点の位置を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

線分の等分でできること

線分の等分は、全長・分割数・間隔のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：等分、分割、割付、目盛り、木工、DIY

入力できる値

項目選べる単位説明
全長mm / cm / m / inch / ft / 尺 / 寸
分割数—区間の数（例: 3分割なら3）
間隔mm / cm / m / inch / ft / 尺 / 寸

計算で求まる値

  • 全長mm / cm / m / inch / ft / 尺 / 寸
  • 分割数
  • 間隔mm / cm / m / inch / ft / 尺 / 寸

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 全長・分割数→間隔
  • 全長・間隔→分割数
  • 分割数・間隔→全長

DIYでの使いどころ

等分は「間隔の数」が1つ少ない

1800mmに4つの穴を等間隔であけたい、というとき、 1800 ÷ 4 = 450 とすると端が合いません。 両端に穴を置くなら間隔は3つなので 1800 ÷ 3 = 600mm です。 この「1つ少ない」を間違えると、最後の穴だけずれます。

端の余白を取るかどうかで変わる

棚柱のビス位置のように端から一定の距離を空ける場合は、 まず両端の余白を引いてから、残りを等分します。 端の余白を取る割り付けは、穴の等間隔配置の計算のほうが目的に合います。

割り切れないときは端で吸収する

1800mmを7等分すると1つ約257.1mm。 現場でこの端数を積み上げると誤差がたまるので、 1点ずつ「端から何mm」の位置として測るのが確実です。この計算は各点の位置をその形で出します。

計算式

線分の等分で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 間隔 = 全長 ÷ 分割数
  • 位置 1
  • 位置 2
  • 位置 3
  • 位置 4
  • 位置 5
  • 分割数 = 全長 ÷ 間隔
  • 全長 = 分割数 × 間隔

使い方

  1. 上のボタンから 線分の等分 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

線分の等分のよくある質問

線分の等分は何が分かれば計算できますか？

全長・分割数を入力すると間隔が求まります。全長・間隔を入力すると分割数が求まります。分割数・間隔を入力すると全長が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば分割数・間隔を入れると全長が求まります。逆算用の別画面はありません。

線分の等分で使える単位は何ですか？

全長は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

線分の等分以外の等分・配置の計算もありますか？

あります。等分・配置のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
