勾配の相互変換でできること

勾配の相互変換は、角度・勾配 %・勾配比（1:n の n）・勾配「寸」のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：勾配、こうばい、傾斜、スロープ、水勾配、寸勾配、屋根、角度

DIYでの使いどころ

勾配の言い方は分野ごとに違う

同じ傾きでも、屋根は「4寸勾配」、道路やスロープは「8%」、排水は「1/100」、 図面や工具は「21.8度」と、分野によって言い方が変わります。 現場ではこの3〜4種類が混ざって出てくるため、どれか1つを入れれば残りが出る形にしてあります。

寸勾配とは

「寸」は、水平に10進んだときに何だけ上がるかを表す言い方です。 4寸勾配なら、水平10に対して垂直4。角度でいうと約21.8度、%でいうと40%です。 瓦や金属屋根の仕様書は寸で書かれていることが多く、工具の角度目盛りは度なので、 この2つの行き来がいちばん使われます。

スロープの勾配の目安

車いすが通るスロープは 1/12（約8.3%、約4.8度）以下がひとつの目安とされます。 水がたまらないようにする土間の水勾配は 1/100〜1/50 程度が使われます。 数値の根拠となる基準は用途・地域によって変わるので、実際の施工では必ず該当する基準をご確認ください。

計算式

勾配の相互変換で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • percent = tan(角度) × 100
  • ratio = 1 ÷ tan(角度)（1:n の n）
  • sun = tan(角度) × 10（勾配の「寸」）
  • 角度 = atan(percent ÷ 100)
  • ratio = 1 ÷ tan(角度)
  • sun = tan(角度) × 10
  • 角度 = atan(1 ÷ n)　(1:n)
  • 角度 = atan(sun ÷ 10)

記号の意味：percent = 勾配 %、ratio = 勾配比（1:n の n）、sun = 勾配「寸」

使い方

  1. 上のボタンから 勾配の相互変換 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

勾配の相互変換のよくある質問

勾配の相互変換は何が分かれば計算できますか？

角度を入力すると勾配 %・勾配比（1:n の n）・勾配「寸」が求まります。勾配 %を入力すると角度・勾配比（1:n の n）・勾配「寸」が求まります。勾配比（1:n の n）を入力すると角度・勾配 %・勾配「寸」が求まります。このほか1通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば勾配「寸」を入れると角度・勾配 %・勾配比（1:n の n）が求まります。逆算用の別画面はありません。

勾配の相互変換で使える単位は何ですか？

角度は ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

勾配の相互変換以外の勾配の計算もありますか？

あります。勾配のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
