長さの単位換算でできること

長さの単位換算は、mm・cm・m・inch・ft・尺・寸のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：長さ、センチ、メートル、インチ、フィート、換算、単位、mm

DIYでの使いどころ

インチ材とミリのつきあい方

ホームセンターで「ワンバイフォー（1×4）」「ツーバイフォー（2×4）」として売られている材は、 インチ由来の呼び名ですが、実際の断面はその呼び寸法より小さく、 1×4 は約19×89mm、2×4 は約38×89mm です。 呼び名の 1インチ = 25.4mm をそのまま当てはめると合いません。

尺と寸

1尺は約303.03mm、1寸はその10分の1で約30.3mmです。 合板の 910×1820mm は3尺×6尺、柱の間隔（1間）は約1820mmで、 日本の建材寸法の多くはこの尺貫法が元になっています。 910という半端な数字の由来がここにあります。

換算の桁を間違えない

mm と m は1000倍、cm と m は100倍。 この桁を1つ間違えると、材料の発注が10倍・100倍になります。 入力欄に数字を入れれば全単位が同時に出るので、 発注前にもう一度この画面で見比べるのを習慣にすると事故が減ります。

使い方

  1. 上のボタンから 長さの単位換算 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

長さの単位換算のよくある質問

長さの単位換算は何が分かれば計算できますか？

mmを入力するとcm・m・inch・ft・尺・寸が求まります。cmを入力するとmm・m・inch・ft・尺・寸が求まります。mを入力するとmm・cm・inch・ft・尺・寸が求まります。このほか4通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば寸を入れるとmm・cm・m・inch・ft・尺が求まります。逆算用の別画面はありません。

長さの単位換算で使える単位は何ですか？

mmは mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

長さの単位換算以外の長さ・単位の計算もありますか？

あります。長さ・単位のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
