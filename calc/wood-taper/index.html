テーパー（先細りのカット）の計算

両端の幅と長さから、片側の削り量・角度・勾配を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

テーパー（先細りのカット）でできること

テーパー（先細りのカット）は、太い方の幅・細い方の幅・長さ・傾きの角度のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：テーパー、先細り、斜めカット、脚、勾配、すぼまり、傾斜、カット

項目選べる単位説明
太い方の幅mm / cm / m / inch / ft / 尺 / 寸
細い方の幅mm / cm / m / inch / ft / 尺 / 寸

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 太い方の幅・細い方の幅・長さ→幅の差（両側の合計）・片側の削り量・傾きの角度・勾配・勾配比（1:n の n）
  • 太い方の幅・長さ・傾きの角度→細い方の幅・幅の差（両側の合計）・片側の削り量・勾配・勾配比（1:n の n）

DIYでの使いどころ

テーブル脚の先細り

脚の根元90mm・先端60mm・長さ700mmのように、両端の幅と長さを入れると、 片側を何mm削ればよいか、その傾きが何度かが出ます。 両側を対称に削る場合、片側の削り量は幅の差の半分です。

丸ノコの定規に使う

出た「片側の削り量」を材の端に印し、根元の印と結んだ線に沿って切ります。 テーパー治具を作るときも、この角度（または勾配）をそのまま使えます。 片側だけ削る場合は、幅の差がそのまま削り量になります。

計算式

テーパー（先細りのカット）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 幅の差 = 太い方 − 細い方
  • 片側の削り量 = 幅の差 ÷ 2
  • 角度 = atan(片側の削り量 ÷ 長さ)
  • 勾配 = 片側の削り量 ÷ 長さ × 100
  • 片側の削り量 = 長さ × tan(角度)
  • 細い方の幅 = 太い方 − 片側 × 2

計算例

長さ700mmで幅90mmから60mmへ細くする脚

入力

  • 太い方の幅90 mm
  • 細い方の幅60 mm
  • 長さ700 mm

結果

  • 幅の差（両側の合計）30 mm
  • 片側の削り量15 mm
  • 傾きの角度1.23°
  • 勾配2.14%
  • 勾配比（1:n の n）46.67

使い方

  1. 上のボタンから テーパー（先細りのカット） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

テーパー（先細りのカット）のよくある質問

テーパー（先細りのカット）は何が分かれば計算できますか？

太い方の幅・細い方の幅・長さを入力すると幅の差（両側の合計）・片側の削り量・傾きの角度・勾配・勾配比（1:n の n）が求まります。太い方の幅・長さ・傾きの角度を入力すると細い方の幅・幅の差（両側の合計）・片側の削り量・勾配・勾配比（1:n の n）が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば太い方の幅・長さ・傾きの角度を入れると細い方の幅・幅の差（両側の合計）・片側の削り量・勾配・勾配比（1:n の n）が求まります。逆算用の別画面はありません。

テーパー（先細りのカット）で使える単位は何ですか？

太い方の幅は mm / cm / m / inch / ft / 尺 / 寸、傾きの角度は ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

テーパー（先細りのカット）以外の木工・DIY寸法の計算もありますか？

あります。木工・DIY寸法のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。

  • 円弧・アール（弦と矢から半径）両端の間隔とふくらみから、曲線の半径・弧長・中心角を計算
