縮尺（図面 ⇄ 実寸）の計算

1/50 などの縮尺で、図面上の寸法と実際の寸法を換算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

縮尺（図面 ⇄ 実寸）でできること

縮尺（図面 ⇄ 実寸）は、図面上の寸法・縮尺の分母・実際の寸法のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：縮尺、スケール、図面、実寸、1/50、1/100、製図、模型

入力できる値

項目選べる単位説明
図面上の寸法mm / cm / m / inch / ft / 尺 / 寸
縮尺の分母—1/50 なら 50。1/100 なら 100
実際の寸法mm / cm / m / inch / ft / 尺 / 寸

計算で求まる値

  • 図面上の寸法mm / cm / m / inch / ft / 尺 / 寸
  • 縮尺の分母
  • 実際の寸法mm / cm / m / inch / ft / 尺 / 寸

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 図面上の寸法・縮尺の分母→実際の寸法
  • 実際の寸法・縮尺の分母→図面上の寸法
  • 図面上の寸法・実際の寸法→縮尺の分母

DIYでの使いどころ

図面の縮尺から実寸を出す

1/50の図面で36mmの線は、実寸で1800mm。図面上の寸法に分母を掛けるだけですが、 桁を1つ間違えると18mか180mmになるので、出た値が常識的な大きさかを必ず見てください。

よく使う縮尺

建築の平面図は 1/100 や 1/50、詳細図は 1/20・1/10、 家具の図面は 1/10・1/5 あたりがよく使われます。 現場でスケール（三角スケール）が無いときは、定規で測った寸法をここに入れれば代用できます。

逆に、図面に描くときは

実寸を入れて図面上の寸法を出すこともできます。 「実際の寸法」と「縮尺の分母」を入れると、紙の上で何mmで描けばよいかが分かります。

計算式

縮尺（図面 ⇄ 実寸）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 実寸 = 図面上の寸法 × 縮尺の分母
  • 図面上の寸法 = 実寸 ÷ 縮尺の分母
  • 縮尺の分母 = 実寸 ÷ 図面上の寸法

計算例

1/50の図面で36mmの線が実寸で何mmか

入力

  • 図面上の寸法36 mm
  • 縮尺の分母50

結果

  • 実際の寸法1,800 mm

この例の計算過程

式数字を入れると答え
実寸 = 図面上の寸法 × 縮尺の分母36 × 501,800 mm

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 縮尺（図面 ⇄ 実寸） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

縮尺（図面 ⇄ 実寸）のよくある質問

縮尺（図面 ⇄ 実寸）は何が分かれば計算できますか？

図面上の寸法・縮尺の分母を入力すると実際の寸法が求まります。実際の寸法・縮尺の分母を入力すると図面上の寸法が求まります。図面上の寸法・実際の寸法を入力すると縮尺の分母が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば図面上の寸法・実際の寸法を入れると縮尺の分母が求まります。逆算用の別画面はありません。

縮尺（図面 ⇄ 実寸）で使える単位は何ですか？

図面上の寸法は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

縮尺（図面 ⇄ 実寸）以外の長さ・単位の計算もありますか？

あります。長さ・単位のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
