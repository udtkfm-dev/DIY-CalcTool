底辺・高さ・面積を相互計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

三角形の面積（底辺・高さ）でできること

三角形の面積（底辺・高さ）は、底辺・高さ・面積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：面積、三角形、広さ

入力できる値

項目選べる単位説明
底辺mm / cm / m / inch / ft / 尺 / 寸
高さmm / cm / m / inch / ft / 尺 / 寸
面積mm² / cm² / m² / 坪 / 畳

計算で求まる値

  • 底辺mm / cm / m / inch / ft / 尺 / 寸
  • 高さmm / cm / m / inch / ft / 尺 / 寸
  • 面積mm² / cm² / m² / 坪 / 畳

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 底辺・高さ→面積
  • 面積・底辺→高さ
  • 面積・高さ→底辺

DIYでの使いどころ

底辺 × 高さ ÷ 2 の「高さ」

三角形の面積で間違えやすいのは高さです。 高さとは、底辺に対して直角に測った距離であって、斜めの辺の長さではありません。 斜めの辺しか分からないときは、3辺から求める計算のほうを使ってください。

三角形の切れ端を数える

屋根の妻側、変形地の隅、板の落とし切りなど、DIYで出てくる三角形は たいてい「長方形から切り落とした残り」です。 底辺と高さを実測して入れれば、塗装面積や材料の見当がすぐ付きます。

計算式

三角形の面積（底辺・高さ）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • S = 底辺 × 高さ ÷ 2
  • 高さ = S × 2 ÷ 底辺
  • 底辺 = S × 2 ÷ 高さ

記号の意味：S = 面積

計算例

底辺900mm・高さ600mmの三角形

入力

  • 底辺0.9 m
  • 高さ0.6 m

結果

  • 面積0.27 m²

この例の計算過程

式数字を入れると答え
S = 底辺 × 高さ ÷ 20.9 × 0.6 ÷ 20.27 m²

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 三角形の面積（底辺・高さ） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

三角形の面積（底辺・高さ）のよくある質問

三角形の面積（底辺・高さ）は何が分かれば計算できますか？

底辺・高さを入力すると面積が求まります。面積・底辺を入力すると高さが求まります。面積・高さを入力すると底辺が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば面積・高さを入れると底辺が求まります。逆算用の別画面はありません。

三角形の面積（底辺・高さ）で使える単位は何ですか？

底辺は mm / cm / m / inch / ft / 尺 / 寸、面積は mm² / cm² / m² / 坪 / 畳 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

三角形の面積（底辺・高さ）以外の面積の計算もありますか？

あります。面積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
