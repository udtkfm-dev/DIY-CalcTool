踊り場を含む階段の全長の計算

第1区間・踊り場・第2区間の水平距離から全長を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

踊り場を含む階段の全長でできること

踊り場を含む階段の全長は、第1区間の水平距離・踊り場の奥行き・第2区間の水平距離（無ければ0）・全長のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：階段、踊り場、折り返し、全長

  • 踊り場の奥行きmm / cm / m / inch / ft / 尺 / 寸

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 第1区間の水平距離・踊り場の奥行き・第2区間の水平距離（無ければ0）→全長
  • 全長・踊り場の奥行き・第2区間の水平距離（無ければ0）→第1区間の水平距離
  • 全長・第1区間の水平距離・第2区間の水平距離（無ければ0）→踊り場の奥行き
  • 全長・第1区間の水平距離・踊り場の奥行き→第2区間の水平距離（無ければ0）

DIYでの使いどころ

踊り場を挟むと全長が変わる

直線階段が入らないとき、途中に踊り場を作って折り返します。 このとき必要な水平距離は「第1区間 ＋ 踊り場 ＋ 第2区間」。 折り返す場合は、踊り場から先が反対方向へ戻るので、 必要な奥行きは第1区間と第2区間の長いほうで決まります。

踊り場の奥行きの目安

踊り場は、少なくとも階段の幅と同じ奥行きを取るのが一般的です。 狭いと荷物を持って回れません。 用途によって寸法の基準が定められている場合があるので、 新築・改修では必ず該当する基準をご確認ください。

計算式

踊り場を含む階段の全長で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 全長 = 第1区間 + 踊り場 + 第2区間
  • 第1区間 = 全長 − 踊り場 − 第2区間
  • 踊り場 = 全長 − 第1区間 − 第2区間
  • 第2区間 = 全長 − 第1区間 − 踊り場

使い方

  1. 上のボタンから 踊り場を含む階段の全長 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

踊り場を含む階段の全長のよくある質問

踊り場を含む階段の全長は何が分かれば計算できますか？

第1区間の水平距離・踊り場の奥行き・第2区間の水平距離（無ければ0）を入力すると全長が求まります。全長・踊り場の奥行き・第2区間の水平距離（無ければ0）を入力すると第1区間の水平距離が求まります。全長・第1区間の水平距離・第2区間の水平距離（無ければ0）を入力すると踊り場の奥行きが求まります。このほか1通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば全長・第1区間の水平距離・踊り場の奥行きを入れると第2区間の水平距離（無ければ0）が求まります。逆算用の別画面はありません。

踊り場を含む階段の全長で使える単位は何ですか？

第1区間の水平距離は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

踊り場を含む階段の全長以外の階段の計算もありますか？

あります。階段のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
