45度カット寸法の計算

材の幅から45度カット面の長さと出寸法を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

45度カット寸法でできること

45度カット寸法は、材の幅・カット面の長さ・長い点と短い点の差のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：45度、カット、木工、角度カット、ミッター

項目選べる単位説明
材の幅mm / cm / m / inch / ft / 尺 / 寸45度にカットする材の幅
カット面の長さmm / cm / m / inch / ft / 尺 / 寸45度カットでできる切断面の長さ
長い点と短い点の差mm / cm / m / inch / ft / 尺 / 寸材の両端で生じる長さの差（＝材の幅と同じ）

計算で求まる値

  • 材の幅mm / cm / m / inch / ft / 尺 / 寸
  • カット面の長さmm / cm / m / inch / ft / 尺 / 寸
  • 長い点と短い点の差mm / cm / m / inch / ft / 尺 / 寸
  • 角度（材の両側とも45°）° / rad

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 材の幅→カット面の長さ・長い点と短い点の差・角度（材の両側とも45°）
  • カット面の長さ→材の幅・長い点と短い点の差・角度（材の両側とも45°）
  • 長い点と短い点の差→材の幅・カット面の長さ・角度（材の両側とも45°）

DIYでの使いどころ

45度に切ると切り口はどれだけ長くなるか

幅90mmの材を45度に切ると、切り口の長さは約127mmになります（幅×√2）。 額縁や巾木の留め継ぎで「材の長さが足りない」となる原因のほとんどが、 この伸びぶんを見込んでいないことです。

長い点と短い点の差

45度に切った材は、外側の角（長い点）と内側の角（短い点）で長さが変わります。 その差は材の幅と同じです。図面に書かれている寸法が外側か内側かを確かめないと、 組んだときに材の幅ぶんだけずれます。巾木や見切り材は外側基準で書かれていることが多いので、 切る前に一度確認してください。

切ってから確かめる

丸ノコやスライド丸ノコの45度目盛りは、正確に45.0度とは限りません。 本番の材を切る前に端材で2本切って、突き合わせて90度になるかを差し金で確かめると、 角度のずれが2倍になって見えるので発見しやすくなります。

計算式

45度カット寸法で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • カット面の長さ = 材の幅 × √2
  • 長短差 = 材の幅
  • 材の幅 = カット面の長さ ÷ √2
  • 材の幅 = 長短差

結果

  • 角度（材の両側とも45°）45°

使い方

  1. 上のボタンから 45度カット寸法 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

45度カット寸法のよくある質問

45度カット寸法は何が分かれば計算できますか？

材の幅を入力するとカット面の長さ・長い点と短い点の差・角度（材の両側とも45°）が求まります。カット面の長さを入力すると材の幅・長い点と短い点の差・角度（材の両側とも45°）が求まります。長い点と短い点の差を入力すると材の幅・カット面の長さ・角度（材の両側とも45°）が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば長い点と短い点の差を入れると材の幅・カット面の長さ・角度（材の両側とも45°）が求まります。逆算用の別画面はありません。

45度カット寸法で使える単位は何ですか？

材の幅は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

45度カット寸法以外の木工・DIY寸法の計算もありますか？

あります。木工・DIY寸法のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
