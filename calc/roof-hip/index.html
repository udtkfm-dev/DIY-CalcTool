隅木・谷木の長さの計算

2方向の水平距離と高さから、隅木の実長と勾配を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

隅木・谷木の長さでできること

隅木・谷木の長さは、水平距離（X方向）・水平距離（Y方向）・高さのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：隅木、すみぎ、谷木、寄棟、入隅、対角、登り、屋根

入力できる値

項目選べる単位説明
水平距離（X方向）mm / cm / m / inch / ft / 尺 / 寸軒から棟までの水平距離
水平距離（Y方向）mm / cm / m / inch / ft / 尺 / 寸もう一方の面の水平距離
高さmm / cm / m / inch / ft / 尺 / 寸軒から棟までの垂直方向の高さ

計算で求まる値

  • 隅木の水平投影長mm / cm / m / inch / ft / 尺 / 寸
  • 高さmm / cm / m / inch / ft / 尺 / 寸
  • 隅木の実長mm / cm / m / inch / ft / 尺 / 寸
  • 隅木の勾配° / rad
  • 屋根面の勾配（X方向）° / rad
  • 屋根面の勾配（Y方向）° / rad

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 水平距離（X方向）・水平距離（Y方向）・高さ→隅木の水平投影長・隅木の実長・隅木の勾配・屋根面の勾配（X方向）・屋根面の勾配（Y方向）

DIYでの使いどころ

隅木はどの辺より長い

寄棟や方形屋根の角に入る隅木（すみぎ）は、 X方向・Y方向・高さの3方向すべてに傾いた斜材です。 そのため、どちらか一方の垂木より必ず長くなります。 水平投影長を先に出し、そこから高さを含めた実長を求めます。

隅木の勾配は屋根面より緩い

屋根面が4寸勾配でも、隅木の勾配はそれより緩くなります（水平距離が長くなるため）。 切る角度を屋根面の勾配で取ると合いません。 この計算が出す「隅木の勾配」を使ってください。

計算式

隅木・谷木の長さで使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 隅木の水平投影長 = √(X方向² + Y方向²)
  • 隅木の実長 = √(水平投影長² + 高さ²)
  • 隅木の勾配 = atan(高さ ÷ 水平投影長)
  • 屋根面の勾配（X方向） = atan(高さ ÷ X方向)

計算例

水平3000×3000mm・高さ1200mmの隅木

入力

  • 水平距離（X方向）3,000 mm
  • 水平距離（Y方向）3,000 mm
  • 高さ1,200 mm

結果

  • 隅木の水平投影長4,242.64 mm
  • 隅木の実長4,409.08 mm
  • 隅木の勾配15.79°
  • 屋根面の勾配（X方向）21.8°
  • 屋根面の勾配（Y方向）21.8°

この例の計算過程

式数字を入れると答え
隅木の水平投影長 = √(X方向² + Y方向²)√(3,000² + 3,000²)4,242.64 mm
隅木の実長 = √(水平投影長² + 高さ²)√(4,242.64² + 1,200²)4,409.08 mm
隅木の勾配 = atan(高さ ÷ 水平投影長)atan(1,200 ÷ 4,242.64)15.79°
屋根面の勾配（X方向） = atan(高さ ÷ X方向)atan(1,200 ÷ 3,000)21.8°

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 隅木・谷木の長さ の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

隅木・谷木の長さのよくある質問

隅木・谷木の長さは何が分かれば計算できますか？

水平距離（X方向）・水平距離（Y方向）・高さを入力すると隅木の水平投影長・隅木の実長・隅木の勾配・屋根面の勾配（X方向）・屋根面の勾配（Y方向）が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

隅木・谷木の長さで使える単位は何ですか？

水平距離（X方向）は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

隅木・谷木の長さ以外の屋根の計算もありますか？

あります。屋根のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
