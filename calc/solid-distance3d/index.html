2点間の距離（3次元）の計算

X・Y・Z の座標2点から、直線距離・水平距離・高低差・仰角を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

2点間の距離（3次元）でできること

2点間の距離（3次元）は、点1 の X・点1 の Y・点1 の Z・点2 の X・点2 の Y・点2 の Zのうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：2点間、距離、3次元、座標、xyz、立体、高低差、仰角

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 点1 の X・点1 の Y・点1 の Z・点2 の X・点2 の Y・点2 の Z→ΔX・ΔY・高低差（ΔZ）・水平距離・直線距離・仰角

DIYでの使いどころ

高さが違う2点の距離

敷地の測点、屋根の上と地面、足場の対角など、 高さが違う2点の間の直線距離は、水平距離だけでは出せません。 X・Y・Zの座標を入れると、直線距離・水平距離・高低差・仰角がまとめて出ます。

仰角がわかると材の角度が決まる

2点間の仰角は、そこに渡す部材を何度に切るかにそのまま使えます。 斜めに渡す筋交いやワイヤーの取り付け角度を決めるときに便利です。

計算式

2点間の距離（3次元）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 水平距離 = √(ΔX² + ΔY²)
  • 直線距離 = √(ΔX² + ΔY² + ΔZ²)
  • 仰角 = atan(ΔZ ÷ 水平距離)

計算例

原点から(3000, 4000, 1200)mmの点までの直線距離

入力

  • 点1 の X0 mm
  • 点1 の Y0 mm
  • 点1 の Z0 mm
  • 点2 の X3,000 mm
  • 点2 の Y4,000 mm
  • 点2 の Z1,200 mm

結果

  • ΔX3,000 mm
  • ΔY4,000 mm
  • 高低差（ΔZ）1,200 mm
  • 水平距離5,000 mm
  • 直線距離5,141.98 mm
  • 仰角13.5°

この例の計算過程

式数字を入れると答え
水平距離 = √(ΔX² + ΔY²)√(3,000² + 4,000²)5,000 mm
直線距離 = √(ΔX² + ΔY² + ΔZ²)√(5,000² + 1,200²)5,141.98 mm
仰角 = atan(ΔZ ÷ 水平距離)atan(1,200 ÷ 5,000)13.5°

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 2点間の距離（3次元） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

2点間の距離（3次元）のよくある質問

2点間の距離（3次元）は何が分かれば計算できますか？

点1 の X・点1 の Y・点1 の Z・点2 の X・点2 の Y・点2 の Zを入力するとΔX・ΔY・高低差（ΔZ）・水平距離・直線距離・仰角が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

2点間の距離（3次元）で使える単位は何ですか？

点1 の Xは mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

2点間の距離（3次元）以外の立体・3Dの計算もありますか？

あります。立体・3Dのカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
