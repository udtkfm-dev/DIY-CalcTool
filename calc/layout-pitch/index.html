ピッチ配置（間隔・個数）の計算

全長・間隔・個数のうち2つから残り1つを計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

ピッチ配置（間隔・個数）でできること

ピッチ配置（間隔・個数）は、全長・間隔・個数のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：ピッチ、間隔、個数、配置、木工、DIY、穴、ビス

入力できる値

項目選べる単位説明
全長mm / cm / m / inch / ft / 尺 / 寸
間隔mm / cm / m / inch / ft / 尺 / 寸
個数—配置する点の数（両端含む）

計算で求まる値

  • 全長mm / cm / m / inch / ft / 尺 / 寸
  • 間隔mm / cm / m / inch / ft / 尺 / 寸
  • 個数

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 全長・間隔→個数
  • 全長・個数→間隔
  • 間隔・個数→全長

DIYでの使いどころ

間隔・個数・全長のうち2つで決まる

「1800mmに300mm間隔で並べたら何個か」「12個並べるには何mm間隔か」など、 どの向きにも計算できます。棚受け・ビス・フェンス支柱の割り付けに使います。

「両端に置くか」で1つ変わる

両端にも置く場合、個数は間隔の数より1つ多くなります（1800÷300＝6区間、7個）。 間だけに置く場合は6個です。 どちらの数え方かで1つずれるので、図を見ながら確認してください。

計算式

ピッチ配置（間隔・個数）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 個数 = 全長 ÷ 間隔 + 1
  • 間隔 = 全長 ÷ (個数 − 1)
  • 全長 = 間隔 × (個数 − 1)

計算例

1800mmに300mm間隔で並べる

入力

  • 全長1,800 mm
  • 間隔300 mm

結果

  • 個数7

この例の計算過程

式数字を入れると答え
個数 = 全長 ÷ 間隔 + 11,800 ÷ 300 + 17

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから ピッチ配置（間隔・個数） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

ピッチ配置（間隔・個数）のよくある質問

ピッチ配置（間隔・個数）は何が分かれば計算できますか？

全長・間隔を入力すると個数が求まります。全長・個数を入力すると間隔が求まります。間隔・個数を入力すると全長が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば間隔・個数を入れると全長が求まります。逆算用の別画面はありません。

ピッチ配置（間隔・個数）で使える単位は何ですか？

全長は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

ピッチ配置（間隔・個数）以外の等分・配置の計算もありますか？

あります。等分・配置のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
