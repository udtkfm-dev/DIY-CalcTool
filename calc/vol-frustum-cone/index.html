円錐台の体積（バケツ・植木鉢）でできること

円錐台の体積（バケツ・植木鉢）は、上の直径・下の直径・高さ・容量のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：円錐台、バケツ、植木鉢、プランター、容量、ホッパー、すぼまり、テーパー

  • 容量・上の直径・下の直径→上の半径・下の半径・高さ

DIYでの使いどころ

すぼまった容器の容量

植木鉢・バケツ・じょうごのように、上と下で直径が違う容器は円錐台です。 上の直径・下の直径・高さの3つが分かれば容量が出ます。 上下の平均で円柱として計算すると、実際よりやや小さく出ます。

植木鉢に入る土の量

鉢は上のほうが広いので、見た目より土が入ります。 ふちいっぱいまで入れることはないので、 出た容量の8割くらいを実際の必要量と見ておくと余りません。

計算式

円錐台の体積（バケツ・植木鉢）で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 半径 = 直径 ÷ 2
  • V = π × h × (R² + R×r + r²) ÷ 3
  • 母線 = √(h² + (R − r)²)
  • 側面積 = π × (R + r) × 母線
  • h = 3V ÷ (π × (R² + R×r + r²))

記号の意味：h = 高さ、V = 容量

使い方

  1. 上のボタンから 円錐台の体積（バケツ・植木鉢） の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

円錐台の体積（バケツ・植木鉢）のよくある質問

円錐台の体積（バケツ・植木鉢）は何が分かれば計算できますか？

上の直径・下の直径・高さを入力すると上の半径・下の半径・母線（斜めの長さ）・側面積・体積(mm³)・体積(m³)・体積(L)が求まります。容量・上の直径・下の直径を入力すると上の半径・下の半径・高さが求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば容量・上の直径・下の直径を入れると上の半径・下の半径・高さが求まります。逆算用の別画面はありません。

円錐台の体積（バケツ・植木鉢）で使える単位は何ですか？

上の直径は mm / cm / m / inch / ft / 尺 / 寸、容量は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

円錐台の体積（バケツ・植木鉢）以外の体積の計算もありますか？

あります。体積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
