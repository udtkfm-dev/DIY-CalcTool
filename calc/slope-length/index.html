勾配と距離でできること

別の呼び方・関連する言葉：勾配、高低差、水平距離、斜距離、屋根、スロープ、階段、排水

DIYでの使いどころ

スロープの長さは「水平距離」ではない

50cm の段差にスロープを付けるとき、必要な板の長さは水平距離そのものではなく、 斜めの長さ（斜距離）です。勾配 1/8 で 500mm 上げるなら水平距離は 4000mm、 斜距離は約 4031mm。差はわずかですが、板を切ってから足りないと分かると作り直しになります。

敷地の高低差から必要な長さを出す

庭のアプローチや駐車場のスロープでは、「高低差」と「使える水平距離」が先に決まっていて、 勾配が後から決まることがほとんどです。その2つを入れれば勾配が%・角度・比の形で出るので、 きつすぎないかをその場で判断できます。

計算式

勾配と距離で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • slant = √(rise² + run²)
  • 角度 = atan(rise ÷ run)
  • 勾配% = rise ÷ run × 100
  • rise = run × tan(角度)
  • slant = run ÷ cos(角度)
  • run = rise ÷ tan(角度)
  • slant = rise ÷ sin(角度)
  • rise = slant × sin(角度)
  • run = slant × cos(角度)
  • 角度に換算してから rise = run × tan(角度)

記号の意味：rise = 高低差、run = 水平距離、slant = 斜距離

計算例

水平5000mmで1000mm上がるスロープ

入力

  • 高低差1,000 mm
  • 水平距離5,000 mm

結果

  • 斜距離5,099.02 mm
  • 角度11.31°
  • 勾配 %20%

この例の計算過程

式数字を入れると答え
slant = √(rise² + run²)√(1,000² + 5,000²)5,099.02 mm
角度 = atan(rise ÷ run)atan(1,000 ÷ 5,000)11.31°
勾配% = rise ÷ run × 1001,000 ÷ 5,000 × 10020%

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 勾配と距離 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

勾配と距離のよくある質問

勾配と距離は何が分かれば計算できますか？

高低差・水平距離を入力すると斜距離・角度・勾配 %が求まります。水平距離・角度を入力すると高低差・斜距離・勾配 %が求まります。高低差・角度を入力すると水平距離・斜距離・勾配 %が求まります。このほか6通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば水平距離・勾配「寸」を入れると高低差・斜距離・角度が求まります。逆算用の別画面はありません。

勾配と距離で使える単位は何ですか？

高低差は mm / cm / m / inch / ft / 尺 / 寸、角度は ° / rad から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

勾配と距離以外の勾配の計算もありますか？

あります。勾配のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
