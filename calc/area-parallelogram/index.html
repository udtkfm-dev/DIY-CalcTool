底辺・高さ・面積を相互計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

平行四辺形の面積でできること

平行四辺形の面積は、底辺・高さ・面積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：面積、平行四辺形、広さ

入力できる値

項目選べる単位説明
底辺mm / cm / m / inch / ft / 尺 / 寸
高さmm / cm / m / inch / ft / 尺 / 寸
面積mm² / cm² / m² / 坪 / 畳

計算で求まる値

  • 底辺mm / cm / m / inch / ft / 尺 / 寸
  • 高さmm / cm / m / inch / ft / 尺 / 寸
  • 面積mm² / cm² / m² / 坪 / 畳

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 底辺・高さ→面積
  • 面積・底辺→高さ
  • 面積・高さ→底辺

DIYでの使いどころ

斜めでも面積は「底辺 × 高さ」

平行四辺形の面積は、傾いていても長方形と同じ「底辺 × 高さ」です。 ここでの高さは、底辺に直角に測った距離で、斜辺の長さではありません。 傾きが大きいほどこの差が開くので、斜辺を入れると面積が過大になります。

菱形（ひし形）も同じ

4辺が等しい菱形も平行四辺形の一種なので、この計算がそのまま使えます。 タイルを斜めに割り付けたときの1枚ぶんの面積などに使えます。

計算式

平行四辺形の面積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • S = 底辺 × 高さ
  • 高さ = S ÷ 底辺
  • 底辺 = S ÷ 高さ

記号の意味：S = 面積

計算例

底辺800mm・高さ450mmの平行四辺形

入力

  • 底辺0.8 m
  • 高さ0.45 m

結果

  • 面積0.36 m²

この例の計算過程

式数字を入れると答え
S = 底辺 × 高さ0.8 × 0.450.36 m²

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 平行四辺形の面積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

平行四辺形の面積のよくある質問

平行四辺形の面積は何が分かれば計算できますか？

底辺・高さを入力すると面積が求まります。面積・底辺を入力すると高さが求まります。面積・高さを入力すると底辺が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば面積・高さを入れると底辺が求まります。逆算用の別画面はありません。

平行四辺形の面積で使える単位は何ですか？

底辺は mm / cm / m / inch / ft / 尺 / 寸、面積は mm² / cm² / m² / 坪 / 畳 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

平行四辺形の面積以外の面積の計算もありますか？

あります。面積のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
