コンクリート・モルタルの配合の計算

容積比から、セメント・砂・砂利それぞれの必要量を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

コンクリート・モルタルの配合でできること

コンクリート・モルタルの配合は、仕上がりの体積・セメントの比・砂の比・砂利の比・割増係数のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：配合、調合、セメント、砂、砂利、モルタル、容積比、練る

入力できる値

項目選べる単位説明
仕上がりの体積mm³ / cm³ / m³ / L / mL
セメントの比—容積比の目安: コンクリート（1 : 3 : 6）／モルタル（1 : 3、砂利なし）／強度を出したいとき（1 : 2 : 4）。割増係数は 1.5〜1.7 程度がよく使われます。
砂の比—
砂利の比—モルタルの場合は 0
割増係数—練ると体積が減る分の割増。1.5〜1.7 程度

計算で求まる値

  • セメントmm³ / cm³ / m³ / L / mL
  • 砂mm³ / cm³ / m³ / L / mL
  • 砂利mm³ / cm³ / m³ / L / mL
  • 材料の合計体積mm³ / cm³ / m³ / L / mL

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 仕上がりの体積・セメントの比・砂の比・砂利の比・割増係数→セメント・砂・砂利・材料の合計体積

DIYでの使いどころ

1:3:6 のような容積比

セメント : 砂 : 砂利 の比で配合を指定する方式です。 モルタルなら砂利なしで 1:3 前後、コンクリートは 1:3:6 や 1:2:4 が使われます。 仕上がりの体積を入れると、それぞれの必要量が出ます。

割増係数（材料の合計は仕上がりより多い）

砂と砂利のすき間にセメントと水が入るため、 材料を単純に足した体積より、練り上がりの体積は小さくなります。 そのぶんを見込むのが割増係数で、1.1〜1.3程度がよく使われます。

強度が要る部分は既製品を

この計算は容積比から材料を分けるだけで、強度を保証するものではありません。 構造に関わる基礎は、配合設計された生コンや、 用途を明記した既製の袋詰め製品を使い、必要なら専門家にご確認ください。

計算式

コンクリート・モルタルの配合で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 材料の合計体積 = 仕上がり × 割増係数
  • セメント = 合計 × セメントの比 ÷ 比の合計
  • 砂 = 合計 × 砂の比 ÷ 比の合計
  • 砂利 = 合計 × 砂利の比 ÷ 比の合計

計算例

100Lのコンクリートを1:3:6（割増1.2）で配合する

入力

  • 仕上がりの体積100 L
  • セメントの比1
  • 砂の比3
  • 砂利の比6
  • 割増係数1.2

結果

  • セメント12 L
  • 砂36 L
  • 砂利72 L
  • 材料の合計体積120 L

この例の計算過程

式数字を入れると答え
材料の合計体積 = 仕上がり × 割増係数100 × 1.2120 L
セメント = 合計 × セメントの比 ÷ 比の合計120 × 1 ÷ 1012 L
砂 = 合計 × 砂の比 ÷ 比の合計120 × 3 ÷ 1036 L
砂利 = 合計 × 砂利の比 ÷ 比の合計120 × 6 ÷ 1072 L

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから コンクリート・モルタルの配合 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

コンクリート・モルタルの配合のよくある質問

コンクリート・モルタルの配合は何が分かれば計算できますか？

仕上がりの体積・セメントの比・砂の比・砂利の比・割増係数を入力するとセメント・砂・砂利・材料の合計体積が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

コンクリート・モルタルの配合で使える単位は何ですか？

仕上がりの体積は mm³ / cm³ / m³ / L / mL から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

コンクリート・モルタルの配合以外のコンクリートの計算もありますか？

あります。コンクリートのカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。

  • 容積比での概算です。強度が求められる場合は、質量での配合設計を専門家にご確認ください。
