必要換気量の計算

部屋の容積と換気回数から、1時間あたりの換気量を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

必要換気量でできること

必要換気量は、幅・奥行き・天井高・換気回数・必要換気量のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：換気、換気量、換気回数、24時間換気、m³/h、給気、排気

入力できる値

項目選べる単位説明
幅mm / cm / m / inch / ft / 尺 / 寸
奥行きmm / cm / m / inch / ft / 尺 / 寸
天井高mm / cm / m / inch / ft / 尺 / 寸
換気回数—1時間に室内の空気が入れ替わる回数。住宅の居室は0.5回/h以上が目安

計算で求まる値

  • 部屋の容積mm³ / cm³ / m³ / L / mL
  • 必要換気量L/min / L/s / m³/h / m³/s

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 幅・奥行き・天井高・換気回数→部屋の容積・必要換気量

DIYでの使いどころ

必要換気量 = 気積 × 換気回数

部屋の体積に、1時間あたり何回入れ替えるかを掛けたものが必要換気量（m³/h）です。 換気扇を選ぶときは、この値以上の風量を持つ機種を選びます。

換気回数の目安

住宅の居室は 0.5回/h（建築基準法のシックハウス対策で定められた値）、 台所・浴室・トイレはもっと多い回数が使われます。 用途ごとの必要回数は換気設備の資料をご確認ください。

カタログ風量はそのまま出ない

換気扇のカタログ値は、ダクトが無い状態での風量です。 実際にはダクトの長さや曲がり、フィルタの抵抗で落ちます。 必要換気量ぎりぎりの機種ではなく、余裕のあるものを選んでください。

計算式

必要換気量で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 容積 = 幅 × 奥行き × 天井高
  • 換気量 = 容積 × 換気回数

計算例

4000×3000mm・天井高2400mmの部屋を0.5回/hで換気する

入力

  • 幅4 m
  • 奥行き3 m
  • 天井高2.4 m
  • 換気回数0.5

結果

  • 部屋の容積28.8 m³
  • 必要換気量14.4 m³/h

この例の計算過程

式数字を入れると答え
容積 = 幅 × 奥行き × 天井高4 × 3 × 2.428.8 m³
換気量 = 容積 × 換気回数28.8 × 0.514.4 m³/h

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 必要換気量 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

必要換気量のよくある質問

必要換気量は何が分かれば計算できますか？

幅・奥行き・天井高・換気回数を入力すると部屋の容積・必要換気量が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

必要換気量で使える単位は何ですか？

幅は mm / cm / m / inch / ft / 尺 / 寸、必要換気量は L/min / L/s / m³/h / m³/s から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

必要換気量以外の空調・断熱の計算もありますか？

あります。空調・断熱のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。

ご利用にあたっての注意

  • 本アプリは寸法・数学の計算を支援するツールです。施工の可否や安全性は判断できません。
  • 断熱・空調の性能は建物の状態・気象条件・使い方で大きく変わります。設計や機器選定は必ず専門家にご確認ください。
  • 換気回数の必要値は室の用途・法令・機器の仕様で異なります。ここでは入力した回数にもとづく計算のみを行います。
