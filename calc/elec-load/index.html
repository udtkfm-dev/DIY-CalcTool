負荷電流の合計の計算

機器の消費電力を合計して、流れる電流を計算。ブラウザですぐ使える無料の計算ツールです。

負荷電流の合計でできること

負荷電流の合計は、機器1の消費電力・機器2の消費電力・機器3の消費電力・機器4の消費電力・電圧・余裕率（%）のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：負荷、電流、合計、ブレーカー、容量、アンペア、コンセント、同時使用

DIYでの使いどころ

消費電力を足して電流に直す

電流 = 合計の消費電力 ÷ 電圧。 100Vで600Wと800Wの機器を同時に使うと14A流れます。 一般的な家庭のコンセント回路は15Aか20Aなので、余裕がほとんどありません。

余裕率を見る

起動時に大きな電流が流れる機器（モーター・コンプレッサー）があるため、 定常時の計算値ぴったりでは足りません。 20%程度の余裕を見ておくと、ブレーカーが落ちにくくなります。

同じ回路かどうかを確認する

コンセントが別でも、分電盤で同じブレーカーにつながっていれば合計が効きます。 どのコンセントがどのブレーカーかは、 ブレーカーを1つずつ落として確認すると分かります。

計算式

負荷電流の合計で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 合計電力 = P1 + P2 + P3 + P4
  • 電流 = 合計電力 ÷ 電圧
  • 余裕を見た電流 = 電流 × (1 + 余裕率)
  • 合計電力 = P1 + P2 + P3
  • 合計電力 = P1 + P2
  • 合計電力 = P1

記号の意味：P1 = 機器1の消費電力、P2 = 機器2の消費電力、P3 = 機器3の消費電力、P4 = 機器4の消費電力

計算例

600Wと800Wの機器を100Vで使う（余裕率20%）

入力

  • 機器1の消費電力600 W
  • 機器2の消費電力800 W
  • 電圧100 V
  • 余裕率（%）20

結果

  • 合計の消費電力1,400 W
  • 流れる電流14 A
  • 余裕を見た電流16.8 A

この例の計算過程

式数字を入れると答え
合計電力 = P1 + P2600 + 8001,400 W
電流 = 合計電力 ÷ 電圧1,400 ÷ 10014 A
余裕を見た電流 = 電流 × (1 + 余裕率)14 × 1.216.8 A

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

負荷電流の合計のよくある質問

負荷電流の合計は何が分かれば計算できますか？

機器1の消費電力・機器2の消費電力・機器3の消費電力・機器4の消費電力・電圧・余裕率（%）を入力すると合計の消費電力・流れる電流・余裕を見た電流が求まります。機器1の消費電力・機器2の消費電力・機器3の消費電力・電圧・余裕率（%）を入力すると合計の消費電力・流れる電流・余裕を見た電流が求まります。機器1の消費電力・機器2の消費電力・電圧・余裕率（%）を入力すると合計の消費電力・流れる電流・余裕を見た電流が求まります。このほか1通りの組み合わせに対応しています。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば機器1の消費電力・電圧・余裕率（%）を入れると合計の消費電力・流れる電流・余裕を見た電流が求まります。逆算用の別画面はありません。

負荷電流の合計で使える単位は何ですか？

機器1の消費電力は W / kW から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

負荷電流の合計以外の電気の計算もありますか？

あります。電気のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
