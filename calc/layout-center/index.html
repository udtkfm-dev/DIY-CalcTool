中央配置・左右均等の計算

全幅と対象の幅から、左右の余白を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

中央配置・左右均等でできること

中央配置・左右均等は、全幅・対象の幅・左右の余白のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：中央配置、芯出し、左右均等、木工、DIY、棚、飾り

入力できる値

項目選べる単位説明
全幅mm / cm / m / inch / ft / 尺 / 寸
対象の幅mm / cm / m / inch / ft / 尺 / 寸
左右の余白mm / cm / m / inch / ft / 尺 / 寸

計算で求まる値

  • 全幅mm / cm / m / inch / ft / 尺 / 寸
  • 対象の幅mm / cm / m / inch / ft / 尺 / 寸
  • 左右の余白mm / cm / m / inch / ft / 尺 / 寸

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 全幅・対象の幅→左右の余白
  • 全幅・左右の余白→対象の幅
  • 対象の幅・左右の余白→全幅

DIYでの使いどころ

中央に取り付けるときの余白

幅1800mmの壁の中央に600mmの棚を付けるなら、左右の余白は各600mm。 （全幅 − 対象の幅）÷ 2 です。 逆に、余白を決めてから対象の幅を出すこともできます。

中心線を先に出す

実際の取り付けでは、余白を測るより「壁の中心」に印を付けてから 対象の半分の寸法を左右に振るほうが正確です。 壁が完全な長方形でないことも多いので、上下2か所で中心を出して結ぶと傾きが出ません。

計算式

中央配置・左右均等で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • 余白 = (全幅 − 対象幅) ÷ 2
  • 対象幅 = 全幅 − 余白×2
  • 全幅 = 対象幅 + 余白×2

計算例

幅1800mmの壁の中央に600mmの棚を付ける

入力

  • 全幅1,800 mm
  • 対象の幅600 mm

結果

  • 左右の余白600 mm

この例の計算過程

式数字を入れると答え
余白 = (全幅 − 対象幅) ÷ 2(1,800 − 600) ÷ 2600 mm

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 中央配置・左右均等 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

中央配置・左右均等のよくある質問

中央配置・左右均等は何が分かれば計算できますか？

全幅・対象の幅を入力すると左右の余白が求まります。全幅・左右の余白を入力すると対象の幅が求まります。対象の幅・左右の余白を入力すると全幅が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば対象の幅・左右の余白を入れると全幅が求まります。逆算用の別画面はありません。

中央配置・左右均等で使える単位は何ですか？

全幅は mm / cm / m / inch / ft / 尺 / 寸 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

中央配置・左右均等以外の等分・配置の計算もありますか？

あります。等分・配置のカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
