天井・床の面積の計算

幅・奥行きから天井や床の面積を計算。ブラウザですぐ使える無料の計算ツールです。

この計算をアプリで開く

天井・床の面積でできること

天井・床の面積は、幅・奥行き・面積のうち分かっている値を入力すると、残りの値が自動で求まる計算です。数式を覚えていなくても、図の寸法をタップして数字を入れるだけで答えが出ます。途中式も画面に表示されるので、合っているかその場で確かめられます。

別の呼び方・関連する言葉：天井面積、床面積、クロス、フローリング、リフォーム

計算で求まる値

  • 幅mm / cm / m / inch / ft / 尺 / 寸
  • 奥行きmm / cm / m / inch / ft / 尺 / 寸
  • 面積mm² / cm² / m² / 坪 / 畳

分かっている値から求められる組み合わせ

入力できるところまで入れれば、対応する組み合わせが見つかった時点で自動的に計算されます。

  • 幅・奥行き→面積
  • 面積・幅→奥行き
  • 面積・奥行き→幅

DIYでの使いどころ

天井と床は同じ面積

幅 × 奥行きで、天井にも床にも使えます。 クロスの張り替え、塗装、フローリングやクッションフロアの数量計算の出発点になります。

実測は壁の内側で

図面の寸法は壁の中心（芯々）で書かれていることが多く、 実際に貼る面はそれより壁の厚みぶん狭くなります。 材料を数えるときは必ず内寸を実測してください。

計算式

天井・床の面積で使っている式です。入力した値の組み合わせによって、使われる式が変わります。

  • S = 幅 × 奥行き
  • 奥行き = 面積 ÷ 幅
  • 幅 = 面積 ÷ 奥行き

記号の意味：S = 面積

計算例

6畳（3640×2730mm）の天井面積

入力

  • 幅3.64 m
  • 奥行き2.73 m

結果

  • 面積9.94 m²

S = 幅 × 奥行き3.64 × 2.739.94 m²

この例の数値は、アプリと同じ計算処理を実行して作成しています。表示桁数は小数第2位までです。

使い方

  1. 上のボタンから 天井・床の面積 の画面を開きます。
  2. 図または入力欄をタップして、分かっている寸法を入れます。単位はその場で切り替えられます。
  3. 必要な値がそろった時点で、残りの値と途中式が自動的に表示されます。

入力した値は端末の中だけに保存され、外部へ送信されることはありません。一度開いたあとは通信が切れても計算できます（ホーム画面に追加するとアプリのように起動します）。

天井・床の面積のよくある質問

天井・床の面積は何が分かれば計算できますか？

幅・奥行きを入力すると面積が求まります。面積・幅を入力すると奥行きが求まります。面積・奥行きを入力すると幅が求まります。足りないときは「あと1つ入力すると計算できます」と画面に出ます。

答えの側から逆算できますか？

できます。求めたい値の欄に数字を入れると、逆向きに計算されます。たとえば面積・奥行きを入れると幅が求まります。逆算用の別画面はありません。

天井・床の面積で使える単位は何ですか？

幅は mm / cm / m / inch / ft / 尺 / 寸、面積は mm² / cm² / m² / 坪 / 畳 から選べます。入力中でも単位を切り替えられ、値は自動で換算されます。

天井・床の面積以外の建築・リフォームの計算もありますか？

あります。建築・リフォームのカテゴリページに、この分野の計算をまとめています。ページ下部の関連リンクからたどれます。
